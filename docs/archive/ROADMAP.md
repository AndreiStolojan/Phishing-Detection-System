# ROADMAP

## Scop

Acest document arată etapele mari ale proiectului. Este mai puțin detaliat decât `TODO.md` și mai bun pentru vedere de ansamblu.

## Viziune

Ținta este un MVP backend-centric, clar, demonstrabil și explicabil, terminat la timp pentru lucrarea de licență.

## Etapa 1 - Fundament

Rezultat urmărit:

- backend Express pornit;
- MongoDB conectat;
- auth funcțional;
- structură de proiect clară.

## Etapa 2 - Integrare email

Rezultat urmărit:

- cont de email conectat;
- sincronizare emailuri;
- salvare în MongoDB;
- datele importante extrase corect.

## Etapa 3 - Motor de scanare

Rezultat urmărit:

- reguli phishing implementate;
- scor de risc;
- verdict clar;
- motive clare și persistate.

## Etapa 4 - Acțiuni și control

Rezultat urmărit:

- listare emailuri;
- rezultate de scan afișabile;
- mark safe;
- block sender local;
- eventual move to spam/junk dacă este fezabil simplu.

## Etapa 5 - Explainability și polish

Rezultat urmărit:

- integrare Ollama pentru explicații;
- curățare cod;
- documentație de rulare;
- scenariu bun pentru demo și prezentare.

## Principiu de prioritizare

Ordinea corectă este:

1. flux complet funcțional;
2. stabilitate;
3. claritate;
4. extra-uri.

Orice idee care nu ajută direct la una dintre etapele de mai sus trebuie tratată ca opțională.
