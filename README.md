# Phishing Detection System

Final year bachelor thesis project.

## Structură

- `backend/` - API Express, MongoDB, Gmail sync, scanare phishing, rapoarte.
- `docs/` - documentația proiectului și progresul lucrării.

## Backend local

```bash
cd backend
npm install
npm run dev
```

API-ul local rulează pe:

```text
http://localhost:5500/api/v1
```
